## Claude Code specifics

- Subagents live in `.claude/agents/`, skills in `.claude/skills/`. They are the source
  of truth; Codex and Copilot copies are generated by `python3 scripts/sync_agents.py`.
  Run it after editing any agent or skill.
- Start new features with the `/feature` skill, review with `/review`, adversarial
  testing with `/bug-hunt`, UI checks with `/ux-audit`, and finish a session with `/handoff`.
- Subagents start with an empty context: when you delegate, pass the task slug, the
  relevant file paths, and the acceptance criteria explicitly.
- Hooks in `.claude/settings.json` block dangerous shell commands and edits to secret
  files. If a hook blocks you, do not try to work around it; ask the human.
- Read `memory/progress.md` (latest entries) at the start of a session to pick up where
  the previous session stopped.
